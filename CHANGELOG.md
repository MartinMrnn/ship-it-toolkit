# Changelog

## 1.0.0 · 2026-11-06 · first public release

- **The github-flow skill** for Claude Code: `setup`, `capture`, `start #N`, `ship` and `release vX.Y.Z`, each ending with the manual steps left for you.
- **`set-field.sh`**: sets Status or Priority on an issue by name, never by ID.
- **Issue forms and PR template**, copied into each repository by `setup`.
- **Dev Template**, a public GitHub Project to copy: six statuses, Board, Backlog and Versions views, and built-in automations that move the cards on their own.
